# Changelog

All notable changes to benchmark definitions and result schemas are documented
here. Dates use ISO 8601.

## Unreleased

### Added

- Buyer-facing service packages for a free public baseline, CNY 9,800 migration
  assessment, enterprise pilot, and recurring regression monitoring.
- Customer service offer, internal sales playbook, outreach drafts, and a scope
  confirmation template.
- Draft standard service terms and a conditional data-processing addendum for
  legal, tax, and compliance review before first contracting.
- A public-safe GitHub inquiry form and GitHub Pages deployment workflow.
- Structured issue forms for commercial inquiries, reproducible result
  submissions, and sanitized bug reports.
- Self-reported source attribution on commercial inquiries so channel quality
  can be measured without adding third-party tracking scripts.
- A 1200 x 630 social preview image, canonical metadata, robots policy, and
  sitemap for public discovery.

### Changed

- Repositioned the static site from a launch opportunity map to a buyer-facing
  migration decision service while preserving the evidence ledger and method
  lineage.
- Extended the local brief generator with the selected service package, scope,
  commercial boundaries, and customer responsibilities.
- Tightened buyer-facing claims to distinguish token-based cost estimates from
  provider invoices, repeated attempts from automatic retries, and rollout
  planning from production operations.

  separate quality/reliability directions.

  fingerprints, deployment tags, and run windows.
- Seeded multi-sample long-context generation and executable registry checks.
- Range-safe remote safetensors auditing and remote-HTTP credential protection.
