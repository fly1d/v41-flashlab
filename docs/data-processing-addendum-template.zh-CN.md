服务方仅按订单、本附件和客户书面指令处理数据。客户负责确认处理目的与法律基础、完成必要告知 / 同意、验证样本授权与脱敏、选择允许的数据区域和第三方端点，并确保指令合法。

服务方认为指令可能违法、超出约定或增加重大风险时，应暂停相关处理并通知客户，不得自行扩大用途。任何新增用途、数据类型、区域或第三方处理方均须书面变更。

## 8. 安全事件

服务方发现涉及客户数据的实际或合理怀疑的安全事件后，应在不无故拖延且不晚于 `[48 / 72]` 小时内通知客户。通知应在可得范围内说明事件性质、影响数据、可能后果、已采取和计划采取的措施及联系人。

服务方应保存事件处置记录、配合客户履行法定义务并采取合理减损措施。责任分配和费用承担以适用协议为准，事件通知不构成责任承认。
