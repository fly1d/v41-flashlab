## 2. 项目目标

在客户指定且已授权、已脱敏的业务样本和端点上，对比 `[当前模型 / 端点]` 与 `[候选模型 / 端点]`，依据预先确认的质量、可靠性、延迟、token 用量、成本估算和治理门槛，给出迁移、部分路由或暂缓建议。
