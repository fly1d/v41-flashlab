## 1. 适用与文件关系

本条款适用于服务提供方与客户签署的 V41 FlashLab 订单确认单。订单应写明本条款的版本和日期。涉及个人信息或客户数据处理的冲突，以数据处理附件为准；其他冲突依次以订单、双方主服务协议（如有）和本条款为准。

## 2. 服务与变更

服务方按订单约定的样本、端点、参数、运行次数、评分规则、交付物和排期提供评估服务。任何新增样本、模型、端点、参数组合、人工复核、报告版本、部署或生产操作均属于范围变更，须双方书面确认新增费用和工期。

服务方可以使用具备相当能力的人员和自动化工具完成服务，但不得因此降低约定的数据安全或保密义务。未经书面约定，服务不包含生产系统操作、持续可用性保障、安全认证或法律合规意见。

## 3. 客户责任与依赖

客户应按时提供合法授权、已完成约定脱敏的样本、参考答案 / rubric、端点访问、预算和业务负责人。客户保证其指令、材料及端点使用不侵害第三方权利且符合适用法律及供应商条款。

客户延迟、端点限流或故障、额度不足、第三方平台变更及客户范围变更造成的时间不计入服务工期。等待达到订单约定期限时，服务方可暂停排期或终止未完成部分，并按订单结算已完成工作及不可退第三方费用。

服务费、税费口径、发票、付款节点、第三方费用预算和账户以订单为准。除订单另有约定，服务方仅在首笔款项实际到账且材料就绪后锁定排期。

未经客户书面预授权，服务方不得使可报销第三方费用超过订单预算上限。服务方应按订单提供合理费用凭证和计价假设。成本估算不等同于模型供应商的最终账单。

## 5. 交付与验收

服务方按订单指定方式交付。客户应在订单约定期限内一次性书面列出不符合项并对应具体范围或验收标准；未按期提出有效异议、书面确认接受或完成约定复盘且未保留异议的，视为验收。

对有效异议，服务方按订单提供一次整改和复交。整改仅限使交付物符合原范围，不包括新增样本、规则、模型、结论方向或格式。候选模型未胜出、客户不喜欢独立结论，或已如实记录的第三方端点故障，不构成拒收理由。

## 6. 取消、暂停与终止

- 客户在开工前取消：退还已收服务费的 `[填写]%`，扣除已发生且不可退的第三方费用。
- 客户在开工后取消：按已完成里程碑 / 工时结算，取消费为剩余服务费的 `[填写]%`，另结算已授权第三方费用。
- 服务方无正当理由取消：退还对应未完成部分的服务费；已完成且可独立使用的交付物按订单结算。
- 一方重大违约且在收到书面通知后 `[填写]` 个工作日内未补救的，另一方可终止。

终止不影响终止前已产生的付款、保密、知识产权、责任限制、争议解决及数据删除义务。

## 8. 双向保密

“保密信息”包括一方以书面、口头、视觉或系统访问方式披露且按性质应合理理解为保密的信息。接收方仅为履行订单使用保密信息，仅向确有必要且受不低于本条款约束的人员披露，并采取不低于保护自身同类信息的合理措施。

下列信息不属于保密信息：接收方无违约已公开的信息；接收方在披露前合法知悉的信息；从无保密义务的第三方合法取得的信息；或接收方未使用披露方信息独立开发的信息。依法必须披露时，接收方在法律允许范围内提前通知并仅披露必要部分。

## 9. 数据处理与安全

双方遵循数据最小化原则。服务方仅按客户书面指令和订单处理客户数据，不主动索取 API 密钥、未脱敏原文或无权评测的数据。若服务方接触个人信息、未公开数据，或数据会发送至第三方 / 境外端点，双方须先签署适用的数据处理附件。

服务方应实施与风险相称的访问控制、传输保护、日志和删除措施。安全事件通知期限、子处理方、区域、留存删除及审计证据以数据处理附件为准。
